# KTX Management – UI Prototype v2

Ứng dụng desktop Python/Tkinter cho bài tập Quản lý Ký túc xá.

## Giao diện
- Giao diện sáng, sidebar, dashboard và các thẻ thống kê.
- Các màn hình được chuẩn hóa theo nhóm bảng của hệ thống KTX.
- Hỗ trợ bảng dữ liệu, tìm kiếm, thêm, sửa, xóa và xem chi tiết.
- Các bảng liên quan như Loại phòng, Chi tiết hóa đơn và Thanh toán được hiển thị ở khu vực phù hợp.
- Dữ liệu hiện tại là dữ liệu mẫu để trình diễn giao diện.

## Chạy
```powershell
python main.py
```
Tài khoản demo: `admin / admin`.

## Cấu trúc dữ liệu
Tệp `sql/SQL.sql` chứa cấu trúc cơ sở dữ liệu `QLKyTucXa` và các đối tượng SQL liên quan.
